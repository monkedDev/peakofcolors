## 🌿 О проекте

Интерактивный музейный экспонат цифрового искусства, построенный вокруг строгой дизайн-дисциплины всего **двух цветов**. Страница использует исключительно оливковую и кремовую краски, раскрывая концепцию тактильного веб-минимализма. 

Вся анимация, процедурная фактура мятой бумаги и «живые» векторные сцены написаны вручную и работают аппаратно силами GPU, не нагружая процессор.

---

## ⚡ Главные фишки

* 📜 **Фактура мятой бумаги:** Реалистичный помятый фон, созданный с помощью процедурных градиентов без единого внешнего изображения.
* 🛰️ **Живые SVG-сцены:** Интерактивный код и анимированный HUD-радар для геймдева, работающие на чистом `inline SVG + CSS @keyframes`.
* 💤 **Умный спящий режим:** Анимации автоматически засыпают через *Intersection Observer API*, когда блок уходит из поля зрения.
* 🔄 **Инверсия темы:** Мгновенное переключение цветов местами одной кнопкой без создания грязи и серых оттенков.
* 📋 **Буфер в один клик:** Интерактивное копирование HEX-кодов со встроенным отказоустойчивым механизмом для локального протокола `file://`.

## 📊 Технические параметры

| Параметр | 🟢 Оливковый (`#606c38`) | 🟡 Кремовый (`#fefae0`) |
| :--- | :--- | :--- |
| **Роль на сайте** | Тёмная (Текст, рамки, акценты, инверсия) | Светлая (Фон страницы, карточки, поля) |
| **RGB** | `96, 108, 56` | `254, 250, 224` |
| **Настроение** | Земляное, тихое, честное, «своё» | Тёплое, мягкое, премиальное, бумага |
| **Контрастность** | **5.40:1** (Соответствует стандарту WCAG AA) | Идеальная подложка для долгого чтения |

## 🚀 Быстрый старт

Проект абсолютно автономен и не требует запуска Python-серверов, компиляторов или установки пакетов через `npm`.

1. Склонируй репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейди в папку проекта:
   ```bash
   cd peakofcolors
   ```
3. Просто дважды кликни по файлу `index.html` на своем компьютере. Всё взлетит локально!
